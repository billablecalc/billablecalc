Never forget to start the timer again

BillableCalc Timer is a free Chrome extension for freelancers. It reminds you to start when you open a client’s Figma, Jira or website, asks what to do with the time you were away, and turns your hours into an invoice in one click.

Reminds you on client sites

Add a client’s sites, like figma.com or acme.atlassian.net. Open one with the timer off and you get a reminder: “Working for Acme? Start timer.” Timer running for another client? It offers to switch, so hours never land on the wrong client. Reminders are opt-in per client site, and “Not now” snoozes them for 30 minutes.

Sees only the sites you list

The extension asks access to exactly the client sites you add, nothing else. It never reads page content, keeps no browsing history and has no servers. Hours stay in your browser, with a backup file whenever you want one.

Catches idle and forgotten time

Stepped away while the timer ran? When you’re back, keep that time or remove it in one click. Running for hours? It asks if you’re still working. Every question also shows in the popup with an orange badge, so nothing gets lost when macOS hides notifications.

How it works

  1. Install BillableCalc Timer from the Chrome Web Store and pin it to the toolbar.
  2. Add a client with an hourly rate, then press Start when you begin working.
  3. At the end of the week open Entries, pick the client and press Create invoice. Save the invoice as PDF and send it.

Questions

Do I need an account?

No. Install the extension and start tracking. There is nothing to sign up for.

Where are my hours stored?

In your browser’s local extension storage on your computer. We have no servers that receive them. In Settings you can download a backup file at any time and restore it on another computer. See the privacy policy.

Can the timer see the sites I visit?

Only the sites you add to a client. The browser asks you to allow access to exactly those sites, and the extension only notices when you open one of them, to offer starting the timer or switching to that client. It never reads page content and keeps no browsing history.

What happens when I step away?

If your computer is idle for 15 minutes (you can change this or switch it off) while the timer runs, the extension asks when you’re back whether to keep that time or remove it.

How does “Create invoice” send my hours to the website?

The hours travel inside the link, after the # sign. Browsers never send that part to the server, so the invoice is built on your computer only.

Does the timer keep running if I close the browser?

Yes. The timer stores its start time, so it shows the right time when you open the browser again. Stop it when you finish work, or fix the end time later in Entries.

Can I bill clients in different currencies?

Yes. Each client has its own currency, and totals are shown per currency. An invoice is created for one client at a time.

Why can the invoice total differ by a few cents?

Invoices show hours with two decimals (for example 1.67 h for 1 h 40 min), the way most clients expect. The popup counts exact seconds.

How do I cancel Pro?

Use the “Manage membership” link in your Gumroad receipt. Pro keeps working until the end of the paid period.
